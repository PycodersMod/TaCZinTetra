# TaCZinTetra Shared-Rig 规范

本文件定义模块化枪的统一视觉坐标和数据职责。当前版本使用透明占位图标，后续模型和贴图必须遵守这些挂点语义。

## 坐标约定

- 使用 Minecraft 物品模型坐标：右手为正向基准，枪口朝 `+Z`，枪身中心为原点。
- 所有模块模型以枪身原点为父节点；模块不得通过 Java 代码硬编码额外偏移。
- 第一人称、第三人称和物品栏只允许改变根节点变换，模块挂点名称保持一致。

## 挂点职责

| 挂点 | 数据键 | 视觉职责 |
| --- | --- | --- |
| body | `taczintetra/body` | 枪身主体、握持中心和基础瞄准轴 |
| barrel | `taczintetra/barrel` | 枪管、枪口和弹道方向 |
| magazine | `taczintetra/magazine` | 弹匣外形和装填方向 |
| stock | `taczintetra/stock` | 枪托及后方支撑，不改变枪口轴 |
| optic | `taczintetra/optic` | 倍镜和 ADS 视觉挂点 |
| grip | `taczintetra/grip` | 握把及下方握持挂点 |

## 数据驱动要求

- 模型、贴图、动画引用必须由 Tetra 模块资源或 TaCZ gunpack 数据提供。
- Java 只读取模块选择和运行状态，不根据型号拼接模型路径或写死坐标。
- 缺少模型时使用透明占位资源；缺失资源不得阻断服务端 profile、弹药和维修逻辑。
- 双持使用两个独立的根节点实例；每个实例只绑定对应手的 ItemStack 和运行时状态。

## 验收边界

完成本规范不等于正式模型、第三人称副手渲染或动作透传已经完成；这些仍需实际资源和窗口画面验收。
