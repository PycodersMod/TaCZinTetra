# TaCZinTetra 可配置模块化枪设计

## 目标

先按 `task.md` 完成完整联动闭环，再以用户指定的透明图标、中文名称、五种材料、枪管口径、枪身型号和常规弹匣作为默认数据，确保所有平衡数值、材料和型号可通过 JSON 配置调整。

## 数据与运行时边界

- `config/taczintetra/modules.json` 是默认配置文件，首次启动自动创建；配置包含材料、枪身、枪管、弹匣、副部件、打磨值、热量、耐久、资源和兼容性默认值。
- Java 代码只保留模块槽位、配置 schema 校验和运行时接口；不写死具体材料、型号或数值。
- Tetra 原生模块 JSON 只描述槽位、安装规则和配置键，不把可调平衡值复制到代码或多个资源文件。
- 配置加载失败时使用安全默认对象并记录明确警告，不能阻止普通 TaCZ/Tetra 启动。

## 默认内容

- 主部件名称为 `枪管`、`枪身`、`弹匣`；副部件为 `倍镜`、`枪托`、`握把`。
- 主部件材料为木、石、铁、金、下界合金。
- 枪身型号为手枪、步枪、机枪、狙击枪、霰弹枪。
- 枪管型号包含常见手枪、步枪、机枪、狙击枪口径，以及霰弹和榴弹口径。
- 弹匣首版只有常规弹匣，结构保留未来弹鼓和特殊供弹类型的配置入口。
- 总图标和七类部件图标统一使用 16×16 纯透明 PNG，后续只替换资源不改数据结构。

## 运行时流程

玩家获得 starter gun 后，Tetra 负责模块安装、替换、打磨和工作台交互；配置解析器根据模块键、材料键和打磨等级解析枪械 profile。TaCZ 适配层只负责把 profile 转成其开火、弹道、换弹、动画和 HUD 所需的生命周期调用，服务端维护权威状态，客户端只发送输入意图和显示预测效果。

## 验收

先执行单元测试和 `clean build`，再执行 `runData`。窗口烟测使用独立 Gradle/Java PID，验证进入世界、获得 starter gun、打开 Tetra 加工台与全息球、安装三类主部件和副部件、一次开火、一次换弹、HUD、耐久/修理及普通 TaCZ 回归；关闭时只结束本次 PID。
